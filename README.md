# Social Media Growth

Research-grounded neural knowledge architecture for building and growing social media accounts.

## Current stage

**Human Psychological Core — Foundation Build v0.1**

This repository does not model audience behavior as a linear funnel. It models psychological mechanisms as a dynamic network of nodes, typed connections, boundary conditions, and feedback loops.

## Core neurons

1. Attention
2. Curiosity
3. Valuation & Emotion
4. Identity
5. Trust
6. Connection
7. Social Transmission
8. Reinforcement & Habit

These are candidate core neurons, not immutable truths. They can be revised only when better evidence materially improves the architecture.

## Architecture

```
Core
├── Core Neurons
├── Connector Mechanisms
├── Typed Connections
├── Feedback Loops
├── Boundary Conditions
└── Evidence / Confidence
```

Core principle:

> A connection is not accepted merely because it sounds psychologically plausible. Every material edge must state its mechanism, evidence, boundary conditions, and confidence.

See:
- `architecture/human-psychological-core.md`
- `connections/core-edge-map.md`
- `research/evidence-policy.md`
- `research/sources.md`

## Scope lock

This stage intentionally excludes platform tactics, hook formulas, algorithm optimization, branding systems, editing techniques, monetization, and growth hacks. Those layers will be connected later to this psychological base.

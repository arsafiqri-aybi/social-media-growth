# HPC-01 — Attention

## Definition

Attention is selective prioritization of information under limited processing capacity. In this architecture, attention is not treated as a single "hook response"; it is a family of selection processes.

## Underlying mechanisms

A useful evidence-grounded decomposition is:

1. **Stimulus-driven influence** — physical salience can compete for selection.
2. **Goal-directed influence** — task relevance and current goals shape selection.
3. **Selection history / learned value** — prior reward associations can bias later attention, even when a cue is no longer task-relevant.

Reward learning is therefore a direct bridge between Reinforcement/Valuation and Attention.

## Evidence

Anderson's work and later reviews support value-driven attention as a distinct influence on attentional selection.

A 2025 systematic review covering 23 publications and 52 experiments concluded that reward-associated features can influence later attentional capture, while also identifying methodological weaknesses and relatively weak effects in the traditional VDAC paradigm.

## Boundary conditions

- Attention is not determined by visual salience alone.
- Reward-history effects are real but can be modest and paradigm-sensitive.
- Current goals can compete with learned value and physical salience.
- Laboratory visual-search findings should not be automatically generalized to every social-media behavior.

## Social-media relevance

A post can receive processing priority because it is:
- physically salient;
- relevant to a current goal;
- associated with learned value from prior interactions;
- connected to identity, novelty, uncertainty, or emotion.

"Make it louder" is therefore not a scientifically sufficient attention strategy.

## Core connections

- **HPC-03 Valuation -> Attention**: learned reward/value can bias selection. **Strongly supported.**
- **HPC-08 Reinforcement -> Attention**: reward-learning history can make cues capture later attention. **Strongly supported.**
- **HPC-02 Curiosity -> Attention**: information seeking directs sampling toward informative stimuli. **Strongly supported at mechanism level.**
- **HPC-04 Identity -> Attention**: likely via relevance and social categorization, but direct social-media edge requires more focused evidence. **Emerging.**

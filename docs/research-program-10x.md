# Human Psychological Core — Research Program 10/10

## Status

**RESEARCH PROGRAM: READY**

The program is breadth-first. We will not perfect Attention while the other seven cores remain shallow.

## Research rounds

### R0 — Ontology challenge
Test definitions, overlap, missing mechanisms, and whether any current core should split/merge.

### R1 — Evidence landscape
For all 8 cores, collect meta-analyses/systematic reviews + foundational primary evidence.

### R2 — Mechanism decomposition
Only now derive L1 modules and L2/L3 neurons from evidence.

### R3 — Cross-core edges
Research causation, association, mediation, moderation, inhibition, feedback, and alternative explanations.

### R4 — Measurement + transport
Identify validated measures and explicitly test transfer from general psychology to social-media contexts.

### R5 — Disconfirmation + saturation
Search null findings, contradictions, heterogeneity, publication bias, failed replication, cultural differences, and context failures.

## Breadth-first batching

Each research batch must touch **all eight cores** before any single core gets a second deep-dive pass, unless a critical ontology blocker requires resolution first.

This prevents depth imbalance.

## Source priority

1. meta-analysis
2. systematic review
3. preregistered/replicated experiment
4. strong experiment
5. longitudinal/behavioral study
6. large observational study
7. theoretical synthesis

Foundational older work remains allowed when central.

## Evidence discipline

Every important conclusion becomes an **atomic claim**.

Each claim records:
- exact scope;
- study design;
- population/sample;
- measurement;
- effect estimate when meaningful;
- bias/heterogeneity;
- moderators/boundaries;
- causal status;
- source location;
- ontology implication.

A search result is not evidence until the source itself has been inspected.

## Deliberate disconfirmation

Every core gets explicit searches for:

- null effects;
- failed replication;
- weak effects;
- information/behavior avoidance;
- reverse or bidirectional effects;
- methodological criticism;
- publication bias;
- heterogeneity;
- cultural differences;
- scope/transport failures.

## Special ontology risks

Four areas receive early scrutiny:

1. **Valuation vs Emotion** — may need a split.
2. **Reinforcement vs Habit** — related but not identical mechanisms.
3. **Trust vs Connection vs Identity** — high risk of construct overlap.
4. **Social Transmission** — observed behavior must remain separate from motives and algorithmic/network distribution.

## Saturation

We do not stop because the bibliography is large.

After broad coverage, each unit requires **two targeted gap/disconfirmation passes**.

Practical saturation is reached only when both passes add no:
- new core candidate;
- core split/merge;
- major module family;
- high-impact contradiction;
- direction-changing moderator;
- measurement invalidation;
- reasoning-changing causal pathway.

At that point, further research should mainly refine detail.

## Scientific non-negotiables preserved

- impression ≠ attention;
- selection/click ≠ curiosity;
- completion ≠ satisfaction;
- engagement ≠ trust;
- follow ≠ loyalty;
- return ≠ habit;
- repeated engagement ≠ parasocial relationship;
- share ≠ unique transmission motive;
- correlation ≠ causation;
- platform A/B label ≠ guaranteed randomized experiment;
- audience cluster ≠ validated audience truth;
- scientific evidence strength ≠ effect size ≠ runtime coefficient;
- account-local success ≠ scientific proof.

## What remains

The next frontier is no longer "build more architecture by default."

The next high-value work is empirical:

1. ingest real account observations;
2. establish account-specific baselines/calibration;
3. generate predictions before interventions;
4. observe outcomes prospectively;
5. accumulate support/falsification/inconclusive records;
6. evaluate diagnostic hit/miss patterns;
7. refine only mechanisms/rules that fail;
8. create platform-specific adapters where repeated evidence justifies them.

Additional scientific research remains appropriate when:
- a provisional mechanism is decision-critical;
- real benchmarks reveal a missing explanation;
- platform behavior materially changes;
- context transport fails;
- measurement cannot distinguish competing explanations.

## Closure decision

`V0_1_FUNCTIONAL_PROGRAM_COMPLETE`

This means:
- the architecture exists;
- measurement boundaries exist;
- reasoning exists;
- adversarial tests exist;
- learning infrastructure exists;
- declared v0.1 gates have passed.

It does **not** mean:
- social-media growth has been scientifically solved;
- every mechanism is saturated;
- the system has universal causal/predictive validity;
- real-account performance improvement has already been demonstrated.

The project should now favor **evidence from use** over uncontrolled ontology expansion.
